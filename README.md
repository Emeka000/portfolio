# Emeka Okoli, Portfolio

Personal portfolio for Emeka Kingsley Okoli, a software engineer building full-stack and on-chain applications across the Stellar and Starknet ecosystems.

Built with Next.js (App Router), TypeScript, Tailwind CSS v4, and Motion.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
